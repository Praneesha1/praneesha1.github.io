# Gajadi Praneesha · Mechanical Design Portfolio

Live site: https://praneesha1.github.io

My portfolio as a Mechanical Engineering student at IIT Jodhpur. It shows my CAD projects from Fusion 360. The engine and the ornithopter open in a 3D viewer in the browser. You can rotate them, pull them apart, cut them open, and run the mechanism.

## Projects

- Four cylinder inline engine
- Ornithopter flapping wing mechanism
- Mechanical components and assemblies

## Made with

HTML, CSS, JavaScript, and three.js. Models exported from Fusion 360.
